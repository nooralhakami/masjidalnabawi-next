إعادة بناء لواجهة الدليل وخريطته بتجربة حديثة وخريطة WebGL، مع البيانات والمنطق نفسيهما من التطبيق الحالي ([masjidalnabawi](https://github.com/nooralhakami/masjidalnabawi)، الذي يبقى كما هو).

- **المفاتيح:** لا يحتاج التطبيق أي مفتاح API (انظر `.env.example`).
