## طريقة القياس
- **`npm run perf`:**
  - يعمل على نسخة البناء، بحجم Pixel 7، وCPU مبطأ 4×، وبلاطات بديلة (stub).
  - يقيس أثناء سحب وتقريب وتدوير مسجّلة: المهام الطويلة، وعمل JS لكل إطار، وزمن الإطار.
- **حدود الحاوية:** WebGL فيها برمجي (SwiftShader)، فزمن الإطار هنا للمقارنة بين نسخ «next» فقط، لا للحكم.
- **الحكم على السلاسة:** على جهاز حقيقي بالخطوات التالية:
  1. Chrome على أندرويد، مع `chrome://inspect` ثم Performance، وCPU 4× حين نريد جهازاً أبطأ.
  2. أو Safari على iPhone، مع Web Inspector ثم Timelines.
  3. سجّل 10 ثوانٍ: سحب، ثم تقريب بإصبعين، ثم تدوير.
  4. سجّل p95 للإطار وأطول مهمة.
